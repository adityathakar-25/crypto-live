# Crypto-Live 🪙

A live cryptocurrency dashboard built with React.

## Features
- Live crypto data from CoinGecko API
- Search, sort and filter coins
- Switch between USD and INR
- Save favourite coins
- Trending coins section
- Individual coin detail page with price chart

## Tech Stack
- React
- React Router DOM
- Chakra UI
- Chart.js
- Axios
- Ant Design (Pagination)

## Run Locally
```bash
npm install
npm run dev
```

## API
Data fetched from [CoinGecko](https://www.coingecko.com/en/api) — free, no API key needed.
